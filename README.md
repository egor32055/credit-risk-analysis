# Анализ кредитоспособности клиентов банка

Учебный аналитический проект по исследованию факторов, связанных с просрочкой по кредиту.

## Задача
Проанализировать данные клиентов банка и проверить, как семейное положение, наличие детей, уровень дохода и цель кредита связаны со своевременным погашением задолженности.

## Данные
Исходный датасет содержит 21 525 наблюдений и 12 признаков: демографические характеристики клиента, тип занятости, доход, семейное положение, наличие детей, цель кредита и факт задолженности.

## Что сделано
- проведена проверка качества данных и обработка пропусков;
- исправлены аномальные значения в трудовом стаже и количестве детей;
- удалены дубликаты и унифицированы текстовые категории;
- выполнена лемматизация целей кредитования;
- созданы категории по уровню дохода и цели кредита;
- рассчитана доля просрочек для различных групп клиентов;
- сформулированы выводы о связи характеристик клиента с возвратом кредита в срок.

## Основные наблюдения
- доля просрочек различается между клиентами с детьми и без детей;
- различия заметны между категориями семейного положения;
- связь уровня дохода с просрочкой выражена слабее и не является монотонной;
- кредиты на операции с недвижимостью в выборке характеризуются меньшей долей просрочек, чем кредиты на автомобили и образование.

> Проект носит исследовательский характер: результаты описывают связи в конкретной выборке и не интерпретируются как причинные эффекты.
